# Prospective source register proposal

Status: pending source/privacy/launch review; no source window is registered or
collected by this document.

The first candidate source is operator-owned Agent Braid runtime metadata from
ordinary-text A/M fixed-patch batches. Source repositories, episode inputs and
workload purpose must be named with exact owner/permission receipts before use.
Repository visibility, code license and previous lab-sync rights are insufficient.

Required registration: source owner and participant/privacy determination;
allowlisted counters and excluded content; immutable workload/resource identities;
start/end of a consecutive source window; enumeration method; episode eligibility;
clock and availability semantics; declared sampling grid; source completeness
check; storage/retention/redaction budget; permission revocation behavior; and
signed/reviewed launch provenance as actually available. A hash is not a signature.

Enumerate every attempted episode and exclusion: missing rights, unsupported
operation, incomplete effects, stale version, missing/late counter, mixed cadence,
insufficient history, missing run outcome, invalid grant, deadline, failed runtime,
unknown resource, duplicate episode or overlapping fold. Keep raw private receipts
and publish only approved aggregates/hashes. Never turn an excluded episode into
a new selected collection window after inspecting favorable outcomes.

Synthetic owned fixtures form a separate rehearsal stratum and cannot satisfy
the permissioned workload utility gate. No admitted real episode count is claimed.

Readiness inspection uses development-pilot outcome values only. Calibration and
holdout outcomes remain sealed while metadata counts, masks and collection
completeness are audited. Freeze the later evaluation population before its
outcomes become visible; pilot-driven design changes never reuse pilot episodes
as an untouched holdout.
