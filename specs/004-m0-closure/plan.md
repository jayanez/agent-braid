# M0 closure plan

Freeze a candidate commit after adding portable workload fixtures, the exit
matrix and deterministic closure checks. Recapture the bounded verifier pilot in
a clean Python 3.12 environment. Run the same read-only prompt sequentially in
Codex and Claude Code against that commit and retain separate reports.

The founder then reviews the evidence and records two decisions: scientific
acceptance of the bounded pilot and formal M0 closure. Only that final phase may
approve the pilot, complete T005 or publish the closure record. An external
reproduction, repository visibility change, package publication and any runtime
claim remain outside this feature.
