# Proposed evaluation and actual outcome contract v1

Registration binds source/rights/window, independent episode unit, grouped folds,
targets/horizons/cadence, model/cheap-method roster, transform/artifact/mapper/
resource/harness identities, full-cost accounting, primary outcome, budgets,
failure rules and decision thresholds. Null approvals/budgets refuse launch.

ForecastReceipt binds cutoff-available inputs, method/version, target/horizon
quantiles, output units/status and actual model preparation/loading/inference/
fallback costs. Do not replace the pinned median with an inferred mean.

PolicyArmReceipt binds immutable input tree, candidate set, decision cutoff,
selected policy, independently obtained operator grant, actual per-step verifier
outcomes, resource operating context, treatment order, total/phase/CPU/memory
costs and raw result hashes. Missing or unexecuted arms have explicit reasons.
Every repeat remains nested under one workload episode.

Report separates forecast metrics, deployment policy utility, synthetic controls,
permissioned actual outcomes, missing/excluded/failed arms and historic context.
Group acceptance cannot use favorable complete cases. Heuristic intervals and
categorical advice are not correctness probabilities. Only actual matched
execution receipts can supply observed alternate-policy costs; shadow does not.
