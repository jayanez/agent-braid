# SPEC-090: Tasks

**Milestone:** provisional, BL.2c (OD-10).

Stable task IDs. Completion requires obtained evidence; task completion does not imply owner acceptance
or support for H1 to H3. Parallelizable is a dependency property and does not authorize concurrent
agents. One pull request per task; the owner approves each merge. Three tasks spend quota, each only
after its freeze and the owner's yes: T020 (gate A noise pilot, development prompts, pilot freeze),
T022 (Gate 0 tripwire run on the frozen twin) and T017 (gate A run). T023 (static Gate 0) spends none. No other task runs a rollout.

`quick` means
`.venv-speckit/bin/python -m scripts.validate_change --base develop --profile quick`.
