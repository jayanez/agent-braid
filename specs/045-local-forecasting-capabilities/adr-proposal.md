# Proposed architecture: local forecasting software

Status: feature-local proposal; canonical adoption pending.

Separate numeric forecasting, economic advisory mapping, transport and execution. Build and validate synthetic engineering under the owner-authorized scope and technical review, while preserving the original FC.1 source/model/launch/promotion gates. Use an optional owned CPU-only local Docker worker with pinned artifacts and verified hard container limits; default APIs remain offline/dependency-free. A model score never issues a grant or changes a verifier, runtime wave or recovery contract. This proposal changes no constitutional article or accepted runtime semantics.
