## Concrete decision packages

1. **Architecture:** [ADR proposal](adr-proposal.md), exact additive interface,
   existing runtime contracts and technical review. Adoption is separate from
   evidence snapshots; no canonical ADR was edited.
2. **Model:** immutable image configuration ID, Linux ARM64 dependency lock and
   license metadata, checkpoint revision/two hashes, local engine, private model
   directory, 2 GiB/CPU1/cold30s/resident1s/300s total conformance budget, bounded
   checkpoint download and owned cleanup. Actual owner approval precedes weights
   and loading; no paid service or automatic cap increase is authorized.
3. **Real sources:** source owners, consent/rights/privacy decision, numeric
   allowlist, immutable source hash, prospective source window, cadence,
   partitions, retention/storage budget, primary groups, exclusions and source
   verifier. Metadata readiness never inspects holdout outcome values.
4. **Launch:** exact candidate/model/source/resource/mapper/monitor/roster hashes,
   reference arms, order seed, warmups/cycles, numerical budgets and external
   per-run grants. Development pilot determines feasibility before holdout.
5. **Interpretation/promotion:** all attempted episodes/groups, complete costs,
   uncertainty, refusals and break-even; proposed median ratio 1.10 with 95%
   lower bound >1.00. Negative, inconclusive and infeasible are valid outcomes.
   A founder decision must bind exact population/resource/artifact; promotion
   cannot be inferred from engineering, GitHub closure or technical review.
