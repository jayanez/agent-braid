after the freeze PR merges). It creates a detached worktree at the pinned commit, runs Codex


```bash
"/Applications/ChatGPT.app/Contents/Resources/codex-cli/bin/codex" exec -s read-only -C ~/Repos/Personal/agent-braid-wt/codex-067-t011 --output-schema specs/067-assurance-profiles/review/codex-t011-20261116.schema.json -o ~/Downloads/codex-067-t011.json "$(cat specs/067-assurance-profiles/review/codex-t011-20261116.md)"
```

The second command runs from the checkout that holds this packet. Model and quota come from
the owner's subscription; no API key is used. Then hand `~/Downloads/codex-067-t011.json` to
the orchestrator session, which records it as
`specs/067-assurance-profiles/evidence/review/codex-t011-20261116.json` with its raw text and
sha256, triages it (confirmed findings get fixes in separate PRs, rejected ones get a written
reason), and re-checks any touched lines independently.

Lab rule: never copy Codex into `/usr/local/libexec/braid` or into `braidlab`'s `PATH`. The
SPEC-065 qualification assumes Codex is absent from the contained environment.
