# Research decisions

The pinned upstream surface spans prompt/rules, memory, tool guidance, reusable skills, delegated roles, deterministic helpers and in-loop plugins/hooks. HAR.1 initially edits guidance/context only. The expanded backlog now assigns each additional mechanism a task and qualification boundary. Deeper sequential/parallel refinement is tested against one-round alternatives before any useful scaling claim.

See the [source audit](../../research/harness2-source-audit.md), [coverage matrix](../048-harness-variant-laboratory/capability-coverage.md) and [adaptation map](../048-harness-variant-laboratory/upstream-adaptation.md). Host-specific unsupported features remain explicit; benchmark/cloud stacks are not necessary to the selected owned-repository workload.
