# Implementation readiness

The generic synthetic importer is the first ready increment. T001 fixes the new
interface/provenance boundary; T002–T005 build and test it without provider
services. T006 is two bounded spikes, and T007 is compatibility screening;
provider implementations require later evidence-backed adoption decisions.

| Package | Entry condition | Exit condition | Pending boundary |
|---|---|---|---|
| Generic offline importer | Existing AIM/report baseline and synthetic corpus | SC-001–SC-005 evidence and contract/security review | Human acceptance of new additive interface |
| OpenAI/MCP lifecycle spikes | Primary source version pins and fixed cases | SC-006 positive/negative/inconclusive packet | Source interpretation and provider adoption |
| A2A/NeMo/OTel screening | Source/version discovery | SC-007 screening dispositions | No dependency/provider adoption included |
| Current decision packet | All prior records and structural checks | SC-008 traceable readiness record | Real-source admission, external review, publication |

There is no prerequisite on positive M4 speedup, M3.5 training or a Yang–Baxter
result. Provider uncertainty cannot hold the synthetic generic implementation
hostage or justify stronger semantics. This draft has empty obtained evidence
and human review pending.
