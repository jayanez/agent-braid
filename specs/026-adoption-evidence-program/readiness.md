# Implementation readiness

The first delivery implements a local evidence program with synthetic intake and
negative controls. It can proceed without participants or external reviewers.
Use the existing cross-cutting governance milestone; this does not create a new
product phase or declare community/market adoption.

| Package | Entry condition | Exit condition | Pending boundary |
|---|---|---|---|
| Frame/metrics/pilot plumbing | Fixed synthetic corpus and current strategy baseline | SC-001–SC-003 deterministic evidence | Real source permissions/yield and prospective pilot review |
| Contributions/reproduction | Local metadata/replay contracts | SC-004–SC-005 positive and negative controls | Actual contributor rights and qualifying external reviewer |
| Historical task audit | Pinned current evidence and original obligations | SC-006 current reconciliation preserving frozen bytes | Residual founder/scientific/publication decisions |
| Full program report | All input/protocol hashes and controls | SC-007–SC-008 audit and packet | Public claims and publication authorization |

No task can require positive demand, favorable usability, accepted counterexamples
or independent validation to appear. Negative/inconclusive evidence completes a
sound protocol within its domain. `evidence.json` binds 20 executed synthetic
controls, fixed inputs and the historical reconciliation. Real admitted episodes
and qualifying external reproductions remain zero. Full-profile capture and the
clean candidate freeze are recorded separately; human review remains pending.
