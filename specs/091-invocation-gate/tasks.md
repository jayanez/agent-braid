# SPEC-091: Tasks

**Milestone:** provisional, BL.2c (OD-15).

Stable task IDs. Completion requires obtained evidence; task completion does not imply owner acceptance
or support for H1 to H3. Parallelizable is a dependency property and does not authorize concurrent
agents. One pull request per task; the owner approves each merge. Nine tasks spend quota, each only
after its own freeze (protocol section, labelled items and pinned builds by sha256 on a `develop` commit)
and the owner's yes: T008, T009 and T018 (development pilots, REQ-035), T012 (2×2 factorial), T019
(selection run, only when OD-20 needs it), T023 (gate A on the same build), T021 (Gate 0 run), T015
(held-out run) and T016 (contrast). If the owner chooses explicit-only in OD-26, only T001 and the OD-12
documentation are done and gate B is not run. No other task runs a rollout.
Stops and resumes follow SPEC-090 REQ-037 (REQ-036).

Task ID T020 is retired: it was never assigned, and IDs are not reused.

`quick` means
`.venv-speckit/bin/python -m scripts.validate_change --base develop --profile quick`.
