A task marked `Founder:` is a decision or action only the founder can take; an agent preparing documents never performs it. A task marked `Orchestrator-launched:` is a host probe that the orchestrating Claude session launches through a workflow or derived sessions only after the founder authorizes that individual probe; no authorization carries from one probe to another, coding agents only prepare the log-only scripts, and Agent Braid launches nothing. A task marked `Integrator:` touches files owned by another track. A task marked `Deferred:` is not scheduled. Dependency independence does not authorize concurrent agents, commits, pushes, remote issue creation or autonomous delivery. Requirement and scenario ids are local to SPEC-057 (REQ-001 to REQ-017, SC-001 to SC-017). Surface ids are `workflow-tracks`, `linked-sessions`, `agent-teams` and `batch` everywhere. Mark a task complete only against obtained evidence recorded in `assurance.json`; research completion is not a supported hypothesis, and an inconclusive or negative G1 completes the protocol without supporting H-OR1. No task authorizes execution, a grant, a merge, a spend above EUR 0, a speed claim, a launch, a message or a resume by Agent Braid. SPEC-058 and SPEC-059 tasks live in their own specifications.
