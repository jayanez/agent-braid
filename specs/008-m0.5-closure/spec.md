# M0.5 internal closure and research-preview preparation

## Scope

Close M0.5 against a frozen candidate after a current milestone radar review,
redistributable current-tree report assets, clean internal reproduction and
separate founder decisions. Prepare a research-preview proposal without changing
repository visibility or publishing a release.

## Requirements and acceptance

- REQ-001: Reassess the scientific, technology and market radar at the milestone
  boundary using traceable sources and bounded claim levels. Automated checks
  validate structure, not source freshness or scientific truth.
- REQ-002: Replace the proprietary-template-derived trends report in the current
  tree with an original, editable presentation and rendered PDF. Preserve sources,
  units and limits, and disclose that historical Git objects require a separate
  publication path or documented redistribution authority.
- REQ-003: Reproduce the M0.5 strategy, market, report and repository gates in a
  fresh clone and Python 3.12 environment bound to an exact candidate commit.
- REQ-004: Record separate founder decisions for the bounded M0.5 review,
  milestone closure and research-preview proposal while keeping repository
  visibility unauthorized and `independent_validation: pending`.

## Boundaries

M0.5 does not establish market demand, competitive superiority, source
exhaustiveness, production safety, general confluence or a Yang-Baxter result.
Approval of the proposal is not authorization to make a repository public,
publish a package or redistribute historical material whose rights are unresolved.
