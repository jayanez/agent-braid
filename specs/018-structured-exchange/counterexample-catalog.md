# M3 finite examples and excluded controls

| Case | Observation | Interpretation |
| --- | --- | --- |
| Two inserts after the same base ID with new IDs a and z | Both schedules end as base, a, z. The physical index of z changes when a is already present. | Positive overlapping residual control inside anchored-sequence-v1. |
| Three inserts after the same base ID | Both declared adjacent braid paths end in reversed logical order with one final ordered sequence. | Positive finite braid-path control; raw chronological traces differ. |
| Two inserts at distinct immutable anchors | Both terminal observations agree, but the advisor keeps order. | Conservative proposal baseline, not a negative semantic result. |
| Two raw-index inserts at one coordinate without anchor or stable tie-break | Executing z then a and a then z can yield different sequences. | Conceptual counterexample to promoting untransformed raw-index swaps; outside the validated domain. |
| Delete, unknown/nested anchor, duplicate new ID | Request rejected. | Negative contract controls; no claim about whether another algebra could exchange them. |
| Missing or altered evidence path, hash or authorization bit | Verification is inconclusive. | Negative evidence controls, not an observed semantic divergence. |

The positive cases are generated by
`python3 -m scripts.run_m3_experiment`; the finite domain and its fixed
payload/ID limitation are recorded in that artifact. The raw-index example is
an explanatory counterexample, not an executable claim in this implementation.
