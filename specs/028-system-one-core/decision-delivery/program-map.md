## Reuse and order outside the first lane

First deliver the useful opt-in deterministic verified-plan path through DDP-T01–T08. No model experiment or indefinite study succession is a prerequisite for that software result. In parallel only after explicit assignment, the coordinator can reconcile original task receipts and prepare scope for selected product branches; preserve disjoint ownership and total concurrency limits.

Next implementation choices should reuse existing tasks: selected schema/routing/hooks hardening if a concrete gap exists; SPEC-032/T005 only if catalogue shortlist is selected; T002/T006 only when their exact model/feature prerequisites are met. SPEC-033/T001 criteria drafting can precede actual promotion, but no shadow data capture, learning or activation is authorized here. Learned work follows the existing prospective source/label/budget gates, rather than being hidden inside DDP-T09.

No lane is declared generally complete. Maintain separate dispositions for source implementation, bounded tests/studies, independent software review, representative utility, human/founder adoption and activation. Those dimensions cannot be reduced to a single percentage or checkbox.
