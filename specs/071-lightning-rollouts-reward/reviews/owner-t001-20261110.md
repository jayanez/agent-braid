# SPEC-071 T001 — owner review (2026-11-10)

Reviewed through guided interactive questions: scope (extraction, subscription-only runner, hooks, reward
vector without an LLM judge, anti-reward-hacking controls, CLI), REQ-014 and OD-2.

Decisions:

- Spec, plan and contracts approved as written, with the stale ADR status wording corrected (ADRs 0039 and 0040
  accepted on 2026-11-08).
- REQ-014: the requirement is to run the baseline on the subscription route and report both proportions and
  intervals (`route-changed comparison`); falling inside or outside the T010 interval is a finding, not a pass
  condition.
- OD-2: OpenCode runs only when it reports a subscription credential source; otherwise it is a declared limit
  (`route-unverified`) and BL.1 can close with Claude Code.
- T012 (real baseline, about 60 rollouts of the owner's subscription quota): the owner is asked for an explicit
  yes, with the quota cost, before it runs. Everything else runs with fake hosts.

OD-1 was decided on 2026-11-08 ([founder decisions](../../../docs/development/FOUNDER_DECISIONS_20261108.md),
decision 4). This review does not approve the frozen candidate (`human_review` stays pending).
