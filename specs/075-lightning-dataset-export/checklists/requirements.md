# SPEC-075: Requirements checklist

Quality checklist for the specification; not a proof or approval.

- [ ] Every REQ has one SC with a procedure and a task.
- [ ] Exclusions name training, upload and SPEC-074 semantics.
- [ ] Terms gate (OD-1) is an owner decision, framed as legal, not scientific.
- [ ] Determinism states what is excluded from the digest (`generatedAt`).
- [ ] Text-level merge limit is declared per record.
- [ ] Refusals are bounded and echo no content.
- [ ] No runtime dependency, network or MCP exposure.
- [ ] Manifest schema path named; schema creation owned by the lead.
