              About this view

              This view reports what was observed or declared. A rendered shape, label, counter or compatibility class is not a guarantee, not a safety ordering and not permission to run, schedule or interleave work.

              The viewer is read-only: it never starts, schedules or changes anything. executionAuthorization: false.

              Unknown, unobserved and unverified information is shown as such and is never counted as clean.

              Controls

              • Select an event: click or press Enter on a row of the events table or on an element of the 3D map. The details panel shows it.
              • Esc clears the selection.
              • ? opens this help.
              • Left and Right arrows move between the tabs.
              • 3D map: drag to orbit, scroll to zoom, click to select.

              Dropped attribute names

              Names only, never values. The viewer discards these host attributes before processing.
