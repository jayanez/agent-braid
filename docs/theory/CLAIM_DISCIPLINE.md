# Claim Discipline

Agent Braid spans engineering and mathematics. This vocabulary keeps the boundary honest.

| Label | Permitted meaning |
|---|---|
| `analogy` | Two structures suggest similar questions; no semantics-preserving map is claimed. |
| `hypothesis` | A falsifiable proposition with a stated domain and disproof condition. |
| `heuristic` | A useful predictor without a soundness guarantee. |
| `empirical` | Supported by finite reproducible observations. |
| `exhaustive-finite` | Checked over every member of a precisely bounded finite domain. |
| `formal` | Derived within a named formal system or proof with explicit assumptions. |

## Examples

- “Disjoint files probably commute” is a heuristic.
- “These two operations produced equivalent normalized trees in both tested orders” is empirical.
- “All operations in this finite generated class satisfy the relation” is exhaustive-finite.
- “Braid relations resemble order-independent agent interaction” is an analogy.
- “This defined exchange operator satisfies the Yang–Baxter equation on carrier X” requires formal evidence or an explicitly finite qualification.

Marketing copy, issue titles, talks, and social posts follow the same discipline as papers and source documentation.
