## Delivery protocol

The user authorized subagents and implementation, then explicitly authorized code
review and merge for coherent blocks. Each deliverable receives an independent
`gpt-6-luna` review. Fix confirmed findings, execute quick validation (including
its conservative escalation), then one stable PR profile. Chain dependent increments
into one reviewed block when separate merge would leave an incomplete interface.
Use normal protected PR merge; never weaken branch protection to force delivery.

Mark tasks complete only when their full contract and executed evidence are met.
Mixed tasks report a completed technical portion with human acceptance pending.
Preserve all historical approvals, NO-GO, source windows, schemas and frozen radar.
Fresh reproduction, public claims, rights and founder decisions have their own gates.
