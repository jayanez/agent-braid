# M0 closure record

**Status:** closed by explicit founder decision

**Decision date:** 2026-09-18

M0 is closed as Agent Braid's internal operational and scientifically bounded
foundation. The founder separately approved the bounded `integer-batch-v1`
pilot review and this milestone closure. The signed repository record is
[`founder-review.json`](../../specs/004-m0-closure/founder-review.json).

## What M0 establishes

- canonical terminology, claim discipline, bounded operational semantics and
  experiment protocol;
- versioned AIM and certificate drafts, finite replay checking, negative controls
  CE1–CE5 and the S3 algebraic control;
- portable declarative examples for code-agent and CI/deployment workload origins;
- a Python 3.12 evidence capture, equivalent Codex and Claude Code reviews, and
  repository, contract and Spec Kit validation.

The [exit matrix](M0_EXIT_MATRIX.md) binds each criterion to its authority,
artifact, executable evidence, human gate and limit.

## What this decision does not establish

- independent third-party reproduction or a public research-preview decision;
- production safety, autonomous execution authorization, or security of external
  effects;
- general confluence, contextual equivalence, adapter correctness, a general
  Yang–Baxter result, or a validated universal exchange class.

Independent pilot reproduction remains an M0.5 research-preview gate. Analyzer
corpus reproduction and Git/worktree benchmarking remain M1 work. Privacy and
security review remains mandatory before accepting third-party traces.
