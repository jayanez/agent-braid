# Agent Braid v0.1.0-alpha.1 research preview

**Status:** publication candidate; not yet published

This record does not create or authorize a GitHub release, tag, public repository
or visibility change. Inherited evidence in the eventual clean export uses
explicitly manifested, deterministic redaction of machine-local paths; original
bytes remain in the private archive.

This candidate packages the constitutional and scientific foundation, AIM and
certificate drafts, bounded laboratory, deterministic analyzer, experimental
read-only Git/worktree adapter, synthetic benchmark corpora and reproduction
protocols in a clean Git history.

## Supported interfaces

- `agent-braid analyze` over AIM `0.2.0-draft` records;
- `agent-braid verify` over bounded certificate bundles;
- `agent-braid analyze-git` with a required provenance artifact;
- analysis report `0.1.0-alpha`;
- AIM and Confluence Certificate `0.1.0-draft` and `0.2.0-draft`.
