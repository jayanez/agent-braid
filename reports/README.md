# Reports

`agent-braid-market-trends-2026.pptx` is the editable M0.5 international trends
report. `agent-braid-market-trends-2026.pdf` is its rendered preview. The current
deck was created from a blank presentation with an original navy, cyan, coral,
cream and white design system. It does not contain the OpenAI **Market Industry
Trends Report** template or its layouts. The cover artwork was generated
specifically for Agent Braid and is stored in `reports/assets/`.

An earlier private commit contained a derivative of that proprietary template.
Replacing the working-tree files does not remove historical Git objects. The
current artifacts are covered by the repository license map, but the private
history remains subject to the distribution boundary recorded in
[`docs/development/THIRD_PARTY.md`](../docs/development/THIRD_PARTY.md). A public
research preview should therefore use the proposed clean export unless rights to
redistribute the historical derivative are documented or a separately approved
history operation resolves it.

Quantitative inputs and limitations are maintained in
[`research/market/2026-opportunity-model.json`](../research/market/2026-opportunity-model.json).
Speaker notes identify sources and claim boundaries. Update the report only at a
milestone review, not from an unreviewed weekly radar result.
