# Benchmarks

Benchmarks compare Agent Braid against sequential execution, naive parallelism, syntactic overlap, Git merge analysis, dependency-aware scheduling, and relevant current competitors.

Every published result must identify the commit, fixtures, environment, versions, repetitions, exclusions, and assurance level.

No performance benchmark has been run. The [laboratory](../lab/README.md) contains
finite diagnostics, not live-agent measurements. Before H5 testing, register a
task-level paired design, hold-outs, correctness non-inferiority margin and cost
thresholds. Include contemporary state-management comparators from
[the reference index](../REFERENCES.md); do not attribute novelty to classical
commutativity or convergence mechanisms.
