# Benchmarks

Every published result must identify the commit, fixtures, environment, versions, repetitions, exclusions, cost boundary and assurance level.

## Obtained bounded engineering measurements

As of 2026-10-05, Git preparation measurements exist in [SPEC-012](../../specs/012-m2-git-replay-planner/spec.md) and [SPEC-013](../../specs/013-m2-real-workload/spec.md). [SPEC-021](../../specs/021-m4-alpha-runtime/measurement-protocol.md) records six paired private-runtime trials; its [G4 decision](../../specs/021-m4-alpha-runtime/g4-decision.json) is NO-GO on useful acceleration under the current descriptive evidence. These records cover their own fixed-patch Git domains, not live adaptive agents or universal runtime benefit.

The [laboratory](../lab/README.md) contains finite diagnostics. H5 testing on live/adaptive-agent workloads still needs a registered task-level paired design, held-out families, correctness non-inferiority margin and complete cost boundary. Contemporary comparators from [the reference index](../REFERENCES.md) require artifact-level feasibility and matched semantics before comparison; classical commutativity and convergence are prior art.

[The foundational implementation portfolio](../../docs/development/FOUNDATION_IMPLEMENTATION_PORTFOLIO.md) identifies planned follow-up protocols. Draft packages and tests are not obtained measurements or evidence of adoption.
