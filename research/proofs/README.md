# Proofs

This directory will contain formal statements, machine-checked developments, or carefully delimited handwritten proofs. Every artifact must state its assumptions, carrier objects, equality/equivalence notion, and relation to executable semantics.

Tests and finite enumeration belong in experiments unless their finite scope is the theorem.

Current [restricted theorem targets](../../docs/theory/OPERATIONAL_SEMANTICS.md#restricted-theorem-targets)
contain unmechanized proof sketches for independence and schedule equivalence.
There are no machine-checked developments here yet. The S3 experiment checks a
known finite construction and does not establish a theorem about agent tools.
